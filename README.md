# Notex for Mac

Official signed and Apple-notarized Notex releases for macOS 26 or later.
Supports Apple Silicon and Intel; AI features require compatible hardware and Apple Intelligence.

[Website](https://notex-swart.vercel.app) · [Download Notex](https://github.com/juanmaramos/notex-releases/releases/latest/download/Notex.dmg) · [Release notes](https://github.com/juanmaramos/notex-releases/releases)

Open the DMG and drag Notex into Applications. Choose **Notex → Check for Updates…** for future versions.

This repository contains public release packages and the signed Sparkle update feed. It does not contain the private application source.
